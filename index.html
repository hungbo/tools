tools.

Runs in your browser

Fix a file without uploading it.

Four small tools for PDFs and images. Each one does its work inside this tab, so the file never reaches a server and there is nothing to sign up for.

Merge PDF

Combine several PDFs into one, in the order you set.

Split PDF

Pull a page range out as its own file.

Compress image

Shrink a JPEG, PNG or WebP by quality or width.

Convert image

Move between PNG, JPEG and WebP.
